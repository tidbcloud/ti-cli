# TiDB Cloud CLI v0.2.6

This release corrects the Google Cloud Filesystem region code to the GCP-native form `gcp-us-east1`.

## What's new

- The built-in TiDB Cloud Filesystem placement is now `gcp-us-east1` (`https://gcp-us-east1.drive9.ai`). `ti configure`, `--region`, installers, and telemetry accept this code and reject `gcp-us-east-1`.
- Starter database commands remain limited to the existing AWS and Alibaba Cloud regions.

If a local Filesystem credential was stored under v0.2.5 with `region_code = "gcp-us-east-1"`, update that file to `gcp-us-east1` or import the token again. Commands such as `ti fs list-file-systems` fail closed while any stored credential in the selected profile still uses the old code.

## Upgrade from v0.2.5

Drain and unmount active Filesystem mounts before replacing `ti` and its bundled `ti-drive9` companion, then run:

```bash
ti update --check
ti update
ti --version
```

New installations can use:

```bash
curl -fsSL https://github.com/tidbcloud/ti-cli/releases/download/v0.2.6/install.sh | sh -s -- --yes
export PATH="$HOME/.ti/bin:$PATH"
ti --version
```

## Use the GCP Filesystem region

```bash
ti configure --non-interactive --region-code gcp-us-east1 \
  --tidb-cloud-public-key "$TIDB_CLOUD_PUBLIC_KEY" \
  --tidb-cloud-private-key "$TIDB_CLOUD_PRIVATE_KEY"

ti --region gcp-us-east1 fs list-file-systems
```
